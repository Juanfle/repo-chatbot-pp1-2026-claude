# Chatbot PP1

## Objetivo
Chatbot básico de ejemplo, desarrollado en el contexto de la materia Prácticas Profesionalizantes I. Responde a un conjunto fijo de palabras clave mediante lógica `if/else`.

## Cómo utilizarlo
1. Clonar el repositorio.
2. Abrir el archivo `index.html` en el navegador (se puede usar directamente o con la extensión "Live Server" de VSCode).
3. Escribir un mensaje en el campo de texto y presionar "Enviar".

## Palabras clave que reconoce
| El usuario escribe (contiene...) | El bot responde |
|---|---|
| `hola` | ¡Hola! ¿En qué te puedo ayudar? |
| `horario` | Atendemos de 9 a 18hs, de lunes a viernes. |
| `gracias` | ¡De nada! Cualquier cosa, avisame. |
| `chau` / `adios` | ¡Hasta luego! |
| (cualquier otra cosa) | No entendí tu mensaje, ¿podés reformularlo? |

## Cómo clonarlo
```bash
git clone https://github.com/Juanfle/repo-chatbot-pp1-2026-claude.git
cd repo-chatbot-pp1-2026-claude
code .
```
